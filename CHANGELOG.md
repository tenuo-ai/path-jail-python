# Changelog

## 0.4.0 - 2026-11-10

- Add `FdJail` guarded file operations, policy options, capabilities, and attestations.
- Add guarded directory mutations on supported Linux platforms.
- Add `Jail.join_segments()` for independently validated path components.
- Upgrade the `path_jail` Rust core to 0.6.0.
- Upgrade PyO3 to 0.30.
- Add Python 3.14 to the tested and advertised version range.
